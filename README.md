# Scripta

Event sourcing and DDD for Java, without the ceremony.

*Verba volant, scripta manent. Spoken words fly away, written words remain.*

> **Status: early development.** APIs are not stable and nothing is released yet.

## Building

Requires Java 21+. The Maven wrapper is included, so no local Maven install is needed:

```sh
./mvnw verify
```
